# x7anth.recorder

Лёгкое и минималистичное приложение для записи экрана на Windows, написанное с нуля на чистом **C#** по собственному видению — без чужих шаблонов, лишних надстроек и тяжёлой нагрузки на систему. Программа создана для тех, кому нужен быстрый, прямой и понятный инструмент для записи рабочего стола или игр.

## Ключевые возможности
- **Один самостоятельный файл:** программа поставляется в виде единого `x7anth.recorder.exe` — не требует установки, распаковки архивов или хранения дополнительных файлов рядом. Можно просто перенести на Рабочий стол и сразу пользоваться.
- **Свой лёгкий стек:** написано на чистом C# с упором на скорость, стабильность и минимальное потребление ресурсов.
- **Гибкие параметры записи:** сохранение видео в формате **MP4** с выбором разрешения (**720p** или **1080p**) и частоты кадров (**30 FPS** или **60 FPS**).
- **Запись звука:** поддержка захвата системного звука и аудиоустройств по выбору пользователя.
- **Удобный контроль во время записи:** компактный оверлей статуса, настройка глобальных горячих клавиш для быстрого старта и остановки, а также отображение свободного места на диске.
- **Выбор папки сохранения:** можно задать директорию сохранения по умолчанию или выбирать папку после завершения записи.

## Быстрый старт
1. Перейдите в раздел **Releases** справа на странице репозитория.
2. Скачайте актуальный файл `x7anth.recorder.exe` из блока **Assets**.
3. Поместите его в любое удобное место (например, на Рабочий стол) и запустите двойным кликом.

## Системные требования
- **ОС:** Windows 10 / Windows 11 (x64)
- **Оборудование:** оптимизировано для работы даже на слабых и офисных ПК с минимальным потреблением ОЗУ и CPU.
